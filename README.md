# Bem Estar Local

Crie um site com aba inicial sou cliente e outra sou massoterapeuta. De acordo que o cliente entrar ele vai em busca de um massoterapeuta em sua região. Coloque como opção de região: Aracoiaba, Aratuba, Itapiúna, Baturite e Capistrano. Coloque também as opções de massagem que são: anti estresse, massagem relaxante, ventosa. Também faça um serviço Premium no site serviços a mais do premium (Massoterapeuta)

• Mais visibilidade no app ( serviços que apareceram primeiro e etc)

• Mais oportunidade de clientes

Serviços a mais do premium (Cliente)

• Massagem grátis após 3 meses de usuário

• Cupons de desconto
